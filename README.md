# Ocanas-Lab-Code-for-sex-differences-in-APPSAA
This repository contains the code that was used to generate some of the data and figures for the Ocanas lab paper about sex differences in the APPSAA mouse model (Cox, et al, 2027).

##

## R package dependencies

    Seurat
    hdf5r
    scDblFinder
    presto
    Matrix
    SeuratDisk
    SingleCellExperiment
    ggplot2
    tidyverse
    monocle3
    SeuratWrappers
    patchwork
    dplyr
    ggbeeswarm
    tidyr
    tibble
    fmsb
    scales
    Augur
    seuratdisk-V5




##
This code was used to analyze single cell data generated from our lab, as well as single cell data from public repositories.

The authors that contributed to this code are: Jillian Cox, Sunghwan "Justin" Ko, Sarah Ray, and Sarah Ocanas
